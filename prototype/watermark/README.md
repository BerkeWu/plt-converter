# 去水印原型（Python + pikepdf，仅用于验证识别与去除算法，正式版用 C++/QPDF 重写）

| 脚本 | 处理的水印类型 | 验证结果（2026-11-04，用户提供的真实样例） |
|---|---|---|
| `wm_artifact.py` | 独立对象水印（KSPX 对象 + Artifact 标签），样例 A | 10 页去除后与用户的无水印版渲染差异 0 像素，指令数量完全一致 |
| `wm_flat.py` | 压平的斜铺文字水印（需还原被混色的线条），样例 C、D | 自动估计混色模型并还原颜色；浅灰水印像素 C 页1 43160→1654、D 页1 24158→232；目视检查线条完整 |
| `wm_b.py` | 与纸样同层的店铺信息栏（图片、色块、联系方式文字），样例 B | 去除后与无水印版相差约 0.3% 像素，残留为信息栏内的小图标、徽章和分隔条（需“范围扩展”） |

样例 E（整页位图）不可处理，只提示。

用法：`python3 -I wm_flat.py 输入.pdf 输出.pdf`（B 脚本多一个参数：1=连同品牌名和图标一起去除）
